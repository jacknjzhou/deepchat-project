# PDF和图片文字提取 / pdf-image-text-extractor

---

## 简介

上传图片或 PDF，自动识别并提取其中的文字内容。基于 DeepChat 内置 `read` 工具与本地已配置的视觉模型完成识别，PDF 文字层在本地解析；支持扫描版 PDF 渲染识别、表格内容整理与批量目录处理，输出清晰易读的 Markdown 结果。

**核心价值**

- **零外部依赖**：不请求任何第三方 OCR 或鉴权服务，无需 API Key，开箱即用。
- **本地模型识别**：图片与扫描件由本地配置的视觉模型识别，数据不出本地。
- **格式保留**：尽量保持原文的段落结构、标题层级，提取结果可直接使用。
- **批量处理**：传入目录路径，一次性处理其中所有 PDF 与图片文件。

---

## 功能特性

- **图片文字提取**：内置 `read` 工具调用本地视觉模型识别图片中的所有文字。
- **PDF 文字提取**：内置 PDF 解析器本地提取文字层，多页文档按页输出。
- **扫描版 PDF 识别**：自动检测无文字层的扫描页，用本地脚本（pymupdf，不联网）渲染为高清图片后交由视觉模型识别。
- **表格内容整理**：将 PDF 中的表格数据整理为 Markdown 表格输出。
- **批量目录处理**：传入目录路径，一次性处理其中所有 PDF 与图片文件。
- **结构化输出**：结果以清晰的 Markdown 格式呈现，方便复制或导出。

---

## 使用前提

- **图片/扫描件识别**：当前会话模型支持视觉，或在 Agent 设置中已配置视觉模型。
- **扫描版 PDF 渲染（可选）**：仅处理扫描版 PDF 时需要 `pip install pymupdf`（纯本地 Python 库，无网络请求）。
- 无需任何 API Key。
