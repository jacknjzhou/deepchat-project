# 06 简历筛选

「简历筛选」用于批量初筛简历：输入岗位 JD（职位描述），添加一批简历文件，由 AI 按统一标准打分并给出推荐意见，全程保留历史记录可回溯。

**入口**：左侧栏 →「简历筛选」

---

## 一、发起一次筛选

### 第 1 步：填写职位描述（JD）

页面左上角为「职位描述」区域，两种方式二选一：

| 方式 | 操作 | 支持格式 |
| --- | --- | --- |
| 粘贴文本 | 切到「粘贴文本」标签，把 JD 文字粘贴进输入框 | 纯文本 |
| 上传文件 | 切到「上传文件」标签，点击「选择文件」 | PDF、DOCX、TXT、MD |

填错可点击「移除文件」清除重选。

> 📷 **截图待补充**：JD 录入区域（两种方式）→ `images/06-jd-input.png`

### 第 2 步：添加简历

1. 在「简历文件」区域点击 **「添加简历」**。
2. 一次可多选；右上角实时显示「已选 N/上限」。
3. 超出上限时提示「最多只能添加 N 份简历」，可分批筛选。
4. 误加的简历点击「移除」即可。

> 📷 **截图待补充**：简历文件列表（含计数）→ `images/06-resume-list.png`

### 第 3 步：选择模型并开始

1. 在「模型」处选择用于筛选的模型。
2. 点击 **「开始审阅」**，任务进入队列。
3. 如需中止，点击 **「取消任务」**。

> 💡 筛选批量执行，耗时与简历份数和模型速度相关；任务在后台排队，可切换到其他页面继续工作。

---

## 二、查看筛选结果

### 2.1 任务进度

任务运行中会显示进度统计：

| 指标 | 含义 |
| --- | --- |
| 总数 / 成功 / 失败 | 本任务简历处理情况 |
| 平均分 | 已完成简历的平均得分 |
| 推荐 | 被标记为「推荐」的数量 |

### 2.2 单份简历详情

在左侧任务中选中一份简历后，右侧详情面板按标签页展示：

| 标签页 | 内容 |
| --- | --- |
| 基本信息 | 候选人概况、**得分（如「得分 85」）**、是否「推荐/不推荐」 |
| 初筛评估 | AI 对简历与 JD 匹配度的分析 |
| 面试官评估 | **亮点**、**风险**、建议的**考察问题** |
| HR 汇总 | **最终总结**与 **HR 意见** |
| 简历原文 | 简历原文内容（个别格式不支持内嵌预览时会提示） |

> 📷 **截图待补充**：简历详情面板（含得分与推荐标记）→ `images/06-resume-detail.png`

## 三、任务历史

页面下方「任务历史」区保存所有历史筛选任务：

- 显示每个任务的**状态**与进度。
- 状态含义：**排队中 → 处理中 → 已完成**；异常情况显示 **部分完成 / 失败 / 已取消**。
- 支持 **上一页 / 下一页** 翻页（显示「第 N / M 页」）。
- 点击历史任务可回看当时的 JD 与全部简历结果，随时复查。

## 四、常见问题

**Q：简历数量有上限吗？**
有（页面上实时显示「已选 N/上限」）。数量较多时建议按批次筛选。

**Q：某些简历显示失败？**
多为文件损坏、加密或格式特殊导致。转存为 PDF 后可重新发起一次仅含失败文件的任务。

**Q：「部分完成」是什么意思？**
任务中部分简历成功、部分失败。可查看失败明细后单独补筛。

**Q：筛选结果可以导出吗？**
可在详情页复制评估内容；如需批量导出请联系管理员确认当前版本是否提供导出功能。
