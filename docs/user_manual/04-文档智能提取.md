# 04 文档智能提取

「文档智能提取」用于把**发票、报销单、银行回单**等单据图片或 PDF 自动识别成结构化数据，统一归档管理。识别后的单据可直接进入 [报销整理](05-报销整理.md) 流程。

**入口**：左侧栏 →「文档」

页面顶部有三个视图切换按钮：

| 视图 | 用途 | 详见 |
| --- | --- | --- |
| **单据视图** | 浏览、筛选、确认已识别的单据记录 | 本章 |
| **任务** | 查看每个文件的识别进度与结果 | 本章第四节 |
| **报销整理** | 按人员/期间/类别归类单据并导出 | [05-报销整理](05-报销整理.md) |

> 📷 **截图待补充**：文档页顶部三个视图切换按钮 → `images/04-view-switch.png`

## 一、单据视图

单据视图是已识别单据的总览列表，页面标题为「智能信息提取」。

### 1.1 识别一张单据（手工上传）

1. 在单据视图点击右上角 **「新建识别」**。
2. 选择一个或多个单据文件（支持图片、PDF；一张多页 PDF 中含多张发票时会自动拆分识别）。
3. 系统创建识别任务，文件进入识别队列。
4. 识别完成后，单据记录出现在列表中，状态为「待确认」。

> 📷 **截图待补充**：新建识别弹窗（选择文件）→ `images/04-new-recognition.png`

### 1.2 单据列表与筛选

列表顶部提供以下筛选工具：

| 筛选项 | 说明 |
| --- | --- |
| 类型标签页 | 按单据类型切换（「全部」及各类别） |
| 状态 | 「待确认」「已确认」「全部状态」 |
| 关键字 | 搜索字段值（如发票号、金额、人员姓名） |
| 日期范围 | 开始日期 / 结束日期 |

列表底部显示「共 N 条」总数。

> 📷 **截图待补充**：单据列表及筛选栏 → `images/04-archive-list.png`

### 1.3 确认单据

识别结果由 AI 提取，关键字段（金额、日期、对方名称等）可能需要人工校正：

1. 点击列表中的单据，打开**单据详情**对话框。
2. 左侧显示单据原图/原文件，右侧显示识别出的字段。
3. 核对无误后点击「确认」；有误可直接修改字段值后保存。
4. 确认后的单据状态变为「已确认」，参与报销整理统计。

> 📷 **截图待补充**：单据详情对话框（左原图右字段）→ `images/04-detail-dialog.png`

### 1.4 导出 CSV

1. 设置好筛选条件（导出结果跟随当前筛选）。
2. 点击 **「导出 CSV」**。
3. 选择保存位置，完成后提示「已导出到 {路径}」。

## 二、自动扫描目录

除了手工上传，还可以让软件**监控指定文件夹**，文件夹里出现新单据时自动识别入库。

### 2.1 开启自动扫描

1. 进入 **「设置 > 智能信息提取」**。
2. 添加需要监控的扫描目录（如 `D:\单据扫描件`）。
3. 之后放入该目录（含子目录）的单据文件会被自动发现并识别。

### 2.2 自动扫描的行为约定

| 行为 | 说明 |
| --- | --- |
| 自动识别 | 目录中出现新文件即创建识别任务，无需人工点击 |
| 相对路径记录 | 任务会记录文件相对扫描目录的目录层级（如 `2026-10/交通费/发票1.pdf`），便于区分批次 |
| 重复跳过 | 内容相同的文件（无论文件名是否相同）自动跳过，一轮扫描结束后提示「本轮已跳过 N 个重复文件」 |
| 多发票拆分 | 一个 PDF 内含多张发票时自动拆成多张单据记录 |

> 📷 **截图待补充**：设置中的扫描目录配置页 → `images/04-autowatch-settings.png`

## 三、去重机制

软件按**文件内容**判断重复，而不是文件名：

- 同一份发票先由自动扫描入库、又被手工上传时，第二次会因内容重复而被跳过或标记，不会产生两条记录。
- 因此整理单据时可以放心把文件复制到扫描目录，不会造成重复归档。

## 四、任务视图

点击页面顶部的 **「任务」** 切换到任务视图，可查看每个文件的处理情况。

### 4.1 任务列表

| 列 | 说明 |
| --- | --- |
| 文件 | 文件名（悬停显示完整路径） |
| 文件相对路径 | 去掉扫描目录前缀后的目录层级；手工上传/对话来源的文件显示「—」 |
| 来源 | **手工上传** / **自动扫描** / **对话**（在对话中解析的文件） |
| 类型 | 单据类型 |
| 状态 | 见下表 |

### 4.2 任务状态

| 状态 | 含义 | 需要做什么 |
| --- | --- | --- |
| 排队中 | 在队列里等待识别 | 无需操作 |
| 识别中 | AI 正在提取字段 | 无需操作 |
| 已完成 | 识别成功，记录已入库 | 到单据视图核对确认 |
| 失败 | 识别未成功（文件损坏、模型异常等） | 点击「重试」；多次失败请检查文件是否清晰完整 |

### 4.3 筛选与重试

- 顶部可按 **批次**（每次扫描/上传为一个批次）、**来源**、**状态** 筛选。
- 失败的任务可在行内点击 **「重试」** 重新识别。

## 五、前置条件

- **必须先配置识别模型**：未配置时页面顶部会出现提示条，点击提示中的「去配置」跳转设置。
- 模型需具备视觉能力（能读图片），由管理员在「设置 > 模型提供方」中完成。

## 六、常见问题

**Q：识别出来的金额/日期不对？**
在单据详情中直接修改字段后确认即可。识别准确率与文件清晰度密切相关，建议使用原始扫描件而非翻拍照片。

**Q：一个 PDF 里有 5 张发票，怎么只出来 1 条记录？**
多发票 PDF 会自动拆分，拆分需要几秒钟处理；若仍未拆分，说明该 PDF 的文本层特征未达到自动拆分条件，可手动分别上传每张发票。

**Q：同一张发票为什么会提示重复？**
软件按内容去重，文件名不同但内容相同的文件视为同一张单据，属正常保护机制。

**Q：任务一直「排队中」？**
说明队列中还有更早的任务在处理，或模型服务繁忙；若长时间无进展，尝试在任务行点击「重试」。
