# 05 报销整理

「报销整理」把已识别的单据按 **人员 → 期间 → 类别** 自动归类，帮助报销经办人快速核对材料是否齐全，并一键导出按类别分好的文件包。

**入口**：左侧栏「文档」→ 页面顶部切换到 **「报销整理」** 视图。

> 前置条件：单据需先在 [单据视图](04-文档智能提取.md) 中识别入库并确认。

---

## 一、界面总览

报销整理视图按分组展示单据，每个分组对应一个「人员 + 期间」组合：

```
┌──────────────────────────────────────────────┐
│  [管理类别]  [导出整理包]   [+ 添加分组]        │
├──────────────────────────────────────────────┤
│ ▼ 张三 ｜ 2026-10                            │
│    ├ 交通费        已有 3 份                  │
│    ├ 餐饮费        已有 2 份                  │
│    └ 住宿费        已有 0 份                  │
│ ▼ 未分类                                     │
│    └ （暂无法判断归属的单据）                  │
└──────────────────────────────────────────────┘
```

| 界面元素 | 说明 |
| --- | --- |
| 分组标题 | 一般为「人员姓名 + 费用期间」，由识别结果自动生成 |
| 未分类 | 暂时无法判断归属的单据集中在此 |
| 管理类别 | 维护报销类别及每类所需的材料清单 |
| 导出整理包 | 把归类结果按类别导出为文件夹 |
| 添加分组 | 手工新增一个分组 |

## 二、单据归类

### 2.1 自动归类

识别完成的单据会根据字段内容**自动归入**「人员 + 期间」分组和费用类别。归错的可以在行内调整。

### 2.2 手工调整归属

- **强制未分类**：把某条单据移出当前分组，回到「未分类」。
- **修改所属分组**：在单据行上选择目标分组/类别。
- **自动归类**：对未分类单据重新触发一次自动判断。

### 2.3 添加分组

需要为某位同事手工建立分组时，点击右上角 **「添加分组」**，填写人员与期间即可。

## 三、所需材料对照

每个类别下方会显示**材料对照**信息：

- 该类别报销**要求**的材料种类（如交通费需要：发票 + 行程单）。
- 当前**已有**几份（「已有 N 份」），对照后即可知道还缺什么材料。

材料要求在 **「管理类别」** 中维护：

1. 点击 **「管理类别」**。
2. 新增/编辑类别，填写类别名称与所需材料清单。
3. 保存后，整理视图中的对照信息即时更新。

## 四、导出整理包

1. 点击右上角 **「导出整理包」**（按钮上会显示当前单据总数，如「导出 (23)」）。
2. 选择导出目录。
3. 导出完成后提示「导出完成：N 个文件，{路径}」。

导出结果为按 **分组/类别** 组织的文件夹结构，可直接作为报销附件包提交。

## 五、与对话模块的配合

在对话中发送的单据文件也会进入统一的单据体系（来源标记为「对话」），同样会出现在报销整理中，无需重复上传。

## 六、常见问题

**Q：为什么有单据落在「未分类」？**
通常是识别字段不完整（缺少人员或期间信息）。手工指定归属，或补全字段后点击「自动归类」。

**Q：导出的文件为什么少了？**
导出范围与当前视图数据一致；先检查是否有个别单据仍处于「待确认」或归属被设为「强制未分类」。

**Q：类别清单由谁维护？**
默认提供常用报销类别；如需调整（增删类别、修改所需材料），在「管理类别」中操作，修改对本机生效。
