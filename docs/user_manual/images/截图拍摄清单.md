# 截图拍摄清单

手册各章节中的截图占位符共 **40 张**，本文档汇总拍摄指引。补拍后将图片文件放入本目录（`docs/user_manual/images/`），文件名与下表一致即可，无需修改章节 Markdown（占位符引用路径与文件名一一对应）。

**拍摄通用要求**：

- 使用真实业务数据时注意脱敏（发票号、金额、人员姓名可打码）。
- 窗口宽度保持默认；深色浅色主题任选其一并保持全套一致。
- 截图格式 PNG；如需标注，用红框圈出重点区域。
