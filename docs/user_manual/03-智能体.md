# 03 智能体

「智能体」是带有不同角色、提示词和工具配置的 AI 助手。切换智能体后，对话的风格、能力和可用工具都会随之变化——例如「报销助手」专注于单据识别，「写作助手」专注于文案创作。

---

## 一、切换智能体

1. 点击左侧栏**顶部的智能体名称**（或首次启动时的智能体欢迎页）。
2. 在弹出的智能体列表中，点击要使用的智能体卡片。
3. 列表中每张卡片会标注智能体类型：
   - **DeepChat 智能体**：软件内置的智能体，配置与数据保存在本机。
   - **ACP 智能体**：接入外部智能体服务的类型，由管理员配置。

## 二、管理智能体

在智能体选择页点击 **「管理智能体」** 进入管理界面，可以：

| 操作 | 说明 |
| --- | --- |
| 新建智能体 | 设定名称、头像（支持 emoji）、系统提示词、绑定的模型 |
| 编辑智能体 | 修改提示词、模型、可用的 MCP 工具等 |
| 删除智能体 | 移除不再使用的自定义智能体（内置智能体不可删除） |
| 排序 | 调整智能体在选择页中的显示顺序 |

### 新建智能体的建议

- **提示词写清楚角色与边界**：例如「你是报销单据审核助手，只回答与报销、发票相关的问题」。
- **绑定合适的模型**：识别类任务选视觉能力强的模型；纯文字任务可选用响应更快的模型。
- **按需绑定工具**：不需要联网搜索的智能体可以关掉搜索工具，回答会更聚焦。

## 三、智能体与各模块的关系

- 左侧栏顶部的智能体名称即**当前生效的智能体**，「文档智能提取」「简历筛选」等模块在识别时使用的模型配置在各模块自身的设置中，与对话智能体相互独立。
- 一个智能体可以绑定自己的 MCP 工具集，切换智能体后对话中可用的工具也会变化。

---

## 四、常见问题

**Q：切换智能体后，历史会话还在吗？**
在。会话列表是按智能体分组展示的，切换智能体只会影响**新对话**使用哪个助手。

**Q：为什么我的智能体列表是空的？**
可能是首次启动后未完成初始化，或管理员未下发默认智能体配置。点击「管理智能体」手动新建一个，或联系管理员。
