# 01 快速上手

---

## 一、安装软件

### 1.1 Windows 安装

1. 获取安装包（如 `deepchat-1.2.8-windows-x64.exe`）。
2. 双击运行，进入安装向导。
3. 在「选择安装位置」页面：
   - 全新安装时，默认安装目录为 **`D:\SRIBD\OfficeAgent`**（要求电脑存在 D 盘；若无 D 盘则默认安装在用户目录下）。
   - 如需修改，点击「浏览」选择其他目录。
   - 从旧版本升级时，安装器会自动沿用上次的安装目录，无需干预。
4. 点击「安装」，等待完成。

> 📷 **截图待补充**：安装向导的「选择安装位置」页面（预填 D:\SRIBD\OfficeAgent）→ `images/01-install-dir.png`

### 1.2 macOS 安装

1. 打开 `.dmg` 镜像文件。
2. 将「办公智能体」图标拖入「Applications」文件夹。
3. 首次打开若提示「无法验证开发者」，请在「系统设置 > 隐私与安全性」中点击「仍要打开」。

---

## 二、首次启动

首次启动软件会进入初始化流程：

1. **选择智能体**：从列表中选择默认使用的智能体（可随时更换，见 [03-智能体](03-智能体.md)）。
2. **模型配置**：
   - 若管理员已统一配置模型，直接进入主界面即可。
   - 若提示「模型未配置」，请联系管理员在「设置 > 模型提供方」中完成配置（普通用户无需自行操作）。
3. **进入主界面**：默认进入「对话」页面。

## 三、主界面总览

主界面由三部分组成：

```
┌──────────────┬──────────────────────────────────┐
│  左侧栏       │                                  │
│              │                                  │
│  智能体名称   │           主工作区                │
│  🔍 搜索      │   （对话 / 文档 / 简历筛选 /       │
│  ＋ 新对话    │      扩展 等页面内容）             │
│  🔍 搜索命令  │                                  │
│  🧩 扩展      │                                  │
│  📥 文档      │                                  │
│  🔎 简历筛选  │                                  │
│              │                                  │
│  会话列表     │                                  │
│              │                                  │
│  ⚙ 设置      │                                  │
└──────────────┴──────────────────────────────────┘
```

| 区域 | 说明 |
| --- | --- |
| 智能体名称（顶部） | 显示当前使用的智能体，点击可切换 |
| 搜索框 | 在历史会话中按关键词搜索 |
| 新对话 | 开启一个新的 AI 对话 |
| 搜索命令 | 打开全局命令面板（快捷键 `Ctrl K`），可快速跳转功能 |
| 扩展 | 插件市场、技能、MCP、OCR（见 [07-扩展与技能](07-扩展与技能.md)） |
| 文档 | 单据识别与文件分组（见 [04](04-文档智能提取.md)、[05](05-文件分组.md)） |
| 简历筛选 | 简历批量筛选（见 [06-简历筛选](06-简历筛选.md)） |
| 会话列表 | 历史对话，支持置顶与分组展示 |
| 设置（左下角） | 软件全部配置项（见 [08-设置](08-设置.md)） |

> 📷 **截图待补充**：主界面全景并标注各区域 → `images/01-main-window.png`
> 📷 **截图待补充**：左侧栏功能入口特写 → `images/01-sidebar.png`

## 四、常用快捷操作

| 操作 | 方式 |
| --- | --- |
| 新建对话 | 左侧栏「新对话」按钮 |
| 全局搜索 / 命令面板 | `Ctrl K` 或左侧栏「搜索命令」 |
| 搜索历史会话 | 左侧栏顶部搜索框输入关键词 |
| 切换页面 | 左侧栏对应入口按钮 |
