# 02 对话

「对话」是软件的主页面，可以与 AI 助手自由交流，处理问答、写作、翻译、资料分析等各类事务。

---

## 一、开始一个新对话

1. 点击左侧栏 **「新对话」**（或顶部智能体名称下方的加号按钮）。
2. 在底部输入框中输入问题。
3. 按 `Enter` 发送（`Shift + Enter` 换行）。
4. AI 的回复会流式显示在对话区，生成过程中可点击停止按钮中断。

## 二、会话管理

所有历史对话都显示在左侧栏的会话列表中。

| 操作 | 方式 |
| --- | --- |
| 查找历史会话 | 左侧栏顶部搜索框输入关键词，实时过滤 |
| 置顶会话 | 在会话条目上打开右键菜单选择置顶（置顶项显示在列表最上方） |
| 重命名 / 删除会话 | 会话条目右键菜单 |
| 收起 / 展开左侧栏 | 侧栏边缘或快捷按钮 |

## 三、输入区功能

输入框支持比纯文字更丰富的内容：

| 功能 | 用法 | 说明 |
| --- | --- | --- |
| 发送文字 | 直接输入后回车 | 基础用法 |
| 上传文件 | 点击输入框旁的附件按钮，或直接把文件拖进对话窗口 | 支持 PDF、Word、图片、代码文件等，AI 可读取并解析内容 |
| 发送图片 | 同上 | 支持让 AI 看图说话、提取图片信息 |
| 切换模型 | 点击输入框上方的模型选择器 | 不同模型能力与速度不同，按需选择 |
| 技能面板 | 输入框旁的技能入口 | 调用已安装的技能（见 [07-扩展与技能](07-扩展与技能.md)） |
| 语音输入 / 通话 | 输入框旁的麦克风/通话按钮 | 用语音代替打字 |

## 四、对话中的常见能力

### 4.1 文件解析

把文件拖入对话后，AI 会自动读取文件内容。典型用法：

- 「总结这份 PDF 的要点」
- 「帮我把这张截图里的表格整理成 Excel 格式」
- 「检查这份合同里有没有对我不利的条款」

### 4.2 生成图片

在支持图像生成的模型下，可以直接用文字描述生成图片（例如「画一张公司年会海报」）。

### 4.3 文档预览与编辑（Artifacts）

当 AI 生成长文档、代码或表格时，内容会在右侧的预览面板中展示，可直接查看、复制，部分内容支持在线编辑后继续让 AI 修改。

> 📷 **截图待补充**：Artifacts 预览面板 → `images/02-artifacts.png`

### 4.4 工具调用

启用扩展/技能后，AI 在对话中可以调用外部工具（如搜索网页、读取数据）。工具调用过程会以折叠卡片显示在消息中，点击可展开查看执行详情。

---

## 五、上下文占用与长对话

- 每个会话有上下文长度上限，界面会显示当前上下文占用情况。
- 对话过长时，软件会自动压缩早期内容以继续对话；如需更精准的回答，建议**适时新建对话**，把必要的背景资料重新提供。

---

## 六、常见问题

**Q：发送后一直没回复？**
检查模型是否配置正确（「设置 > 模型提供方」），或网络是否可用；也可能是模型服务繁忙，稍后重试。

**Q：AI 说它看不到我发的文件？**
确认文件已成功上传（消息中应出现文件卡片）；个别加密或扫描质量过低的文件可能解析失败，可转成 PDF 后重试。

**Q：回复中断了？**
可能是网络波动或达到服务限速，点击「继续」或重新发送即可。
