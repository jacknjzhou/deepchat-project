> 版本：v1.2.8 ｜ 适用平台：Windows / macOS ｜ 更新日期：2026-10-14

---

## 一、产品简介

**办公智能体**是一款桌面端 AI 办公助手，围绕日常办公场景提供以下核心能力：

| 模块 | 入口位置 | 主要用途 |
| --- | --- | --- |
| 对话 | 左侧栏「新对话」 | 与 AI 助手自由对话，支持文件解析、图片生成、文档预览编辑 |
| 智能体 | 左侧栏顶部智能体名称 | 在不同角色/助手的智能体之间切换 |
| 文档智能提取 | 左侧栏「文档」 | 单据图片/PDF 自动识别、结构化归档、自动扫描目录 |
| 文件分组 | 「文档」页内切换 | 将识别出的报销单据按人员、期间、类别自动归类并导出 |
| 简历筛选 | 左侧栏「简历筛选」 | 输入岗位 JD，批量筛选简历并保留历史记录 |
| 扩展 | 左侧栏「扩展」 | 插件市场、技能（Skills）、MCP、内置 OCR |
| 设置 | 左侧栏底部「设置」 | 模型配置、显示、快捷键、数据、知识库、关于等 |

## 二、快速上手（5 步）

1. **安装软件**：双击安装包，按引导完成安装（全新安装默认目录为 `D:\SRIBD\OfficeAgent`，可在安装时修改）。
2. **首次启动**：按初始化向导完成基础设置（详见 [01-快速上手](01-快速上手.md)）。
3. **选择智能体**：点击左侧栏顶部的智能体名称，选择要使用的智能体。
4. **开始对话**：点击「新对话」，输入问题或拖入文件。
5. **使用办公模块**：通过左侧栏进入「文档」「简历筛选」等模块处理具体业务。

## 五、遇到问题？

- 单据识别失败 → 见 [04-文档智能提取 > 常见问题](04-文档智能提取.md#六常见问题)
- 模型未配置/不可用 → 见 [08-设置 > 模型提供方](08-设置.md#二模型提供方管理员)
- 找不到某功能 → 使用左侧栏「搜索」或按 `Ctrl K` 呼出全局搜索
- 其他问题 → 联系管理员或在「设置 > 关于」中检查版本更新
