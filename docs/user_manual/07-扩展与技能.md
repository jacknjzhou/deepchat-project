# 07 扩展与技能

「扩展」页面集中管理软件的插件生态，分为四个部分：**扩展目录（插件市场）、技能、MCP、OCR**。

**入口**：左侧栏 →「扩展」

页面左侧为导航：扩展目录 / 技能 / MCP / OCR。

## 一、扩展目录（插件市场）

扩展目录列出可安装的官方与社区插件：

1. 浏览插件卡片，点击进入插件详情页。
2. 详情页展示插件的功能介绍与配置项。
3. 按页面提示完成安装/启用。

安装后的插件能力会融入对话（例如让 AI 具备新的工具调用能力）。

> 📷 **截图待补充**：扩展目录列表 → `images/07-catalog.png`

---

## 二、技能（Skills）

技能是**提示词 + 操作流程**的组合包，让 AI 掌握一项专门本领（如「按公司模板写周报」「按规范生成测试用例」）。

### 使用技能

1. 对话界面点击输入框旁的**技能面板**入口。
2. 选择要使用的技能，按技能指引提供输入内容。
3. AI 会按技能定义的流程输出结果。

### 管理技能

1. 进入「扩展 > 技能」页面。
2. 查看已安装技能清单，可启用/停用/移除。
3. 部分环境支持技能目录同步，页面会显示同步扫描状态。

## 三、MCP

MCP（Model Context Protocol）是连接外部工具/数据源的标准协议。通过 MCP，AI 可以操作企业内部系统（如知识库、工单系统）。

**普通用户注意**：MCP 服务器由**管理员统一配置**后下发，日常使用无需关心；对话中若 AI 调用了 MCP 工具，消息里会出现工具调用卡片，点击可展开查看调用详情。

如需查看：进入「扩展 > MCP」可看到当前已接入的 MCP 服务器及其连接状态。

## 四、OCR（文字识别）

内置 OCR 提供离线的图片文字识别能力，供文档识别等模块在本地完成文字提取。

1. 进入「扩展 > OCR」。
2. 查看/选择 OCR 引擎与语言包。
3. 无特殊需求保持默认即可。

## 五、常见问题

**Q：安装插件后对话里没变化？**
部分插件需要重启对话或重新选择智能体后生效；确认插件处于「已启用」状态。

**Q：技能执行失败？**
检查技能所需的前置条件（如模型配置、文件格式）；技能详情页一般会说明输入要求。

**Q：MCP 显示断开？**
多为企业服务暂不可用，稍后自动重连；持续断开请联系管理员检查服务端。
