# 08 设置

软件的全部配置项集中在「设置」中。

**入口**：左侧栏左下角 → **「设置」**

> 📷 **截图待补充**：设置主界面（含左侧分区导航）→ `images/08-settings-home.png`

## 一、设置分区一览

| 分区 | 内容 | 普通用户是否需要动 |
| --- | --- | --- |
| 通用 | 基础行为设置 | 一般不用 |
| 服务商设置 | 配置 AI 模型服务商与模型 | ❌ 管理员负责 |
| 办公智能体 Agent | 管理智能体及其新会话默认值 | ✔ 按需 |
| 智能信息提取 | 单据识别模板管理 | ✔ 按需 |
| 智能信息提取模型 | 单据识别用的文本/视觉模型 | ❌ 管理员负责 |
| 报销类别配置 | 报销类别、材料清单、字段映射 | ✔ 报销经办人常用 |
| 知识库 | 本地知识库管理 | 按需 |
| 技能 | 技能包管理（亦可从「扩展」进入） | 按需 |
| MCP | 外部工具源配置 | ❌ 管理员负责 |
| 显示 | 主题、语言、字体等外观 | ✔ 常用 |
| 快捷键 | 自定义键盘快捷方式 | ✔ 常用 |
| 通知 | 消息通知行为 | 按需 |
| 数据 | 数据备份、导入导出、清理 | ✔ 建议了解 |

以下对**服务商设置、办公智能体 Agent、智能信息提取、智能信息提取模型、报销类别配置**五个重点分区详细介绍。

## 二、服务商设置（管理员）

模型能力的前提。页面分为**左侧已配置服务商列表**和**右侧服务商平台目录**两部分。

> 📷 **截图待补充**：服务商设置页（密钥注意打码）→ `images/08-providers.png`

### 2.1 添加一个服务商

1. 在右侧目录中**搜索服务商平台**（如 OpenAI 兼容服务、Ollama、ModelScope、Azure、Bedrock、Vertex 等），或点击「添加自定义服务商」。
2. 填写 **API URL**（有格式样例提示，可一键填充）与 **API Key**（附「如何获取」指引）。
3. 点击 **「验证密钥」** 测试连通性。
4. 保存后服务商出现在左侧「已配置」列表。

### 2.2 管理模型

- 每个服务商下有**模型列表**，点击 **「启用模型」** 勾选需要暴露给对话/各功能使用的模型，也可「禁用全部」。
- 点击**刷新**会先同步上游元数据、再重建本地模型列表。
- 部分平台（如 Ollama）支持「运行模型 / 停止模型 / 拉取模型」等本地模型操作。

### 2.3 其他管理操作

| 操作 | 入口 |
| --- | --- |
| 重命名 / 复制 / 禁用 / 删除服务商 | 左侧列表右键菜单（复制可快速创建仅网址不同的服务商） |
| 自定义请求头 | 以 JSON 对象填写（值为字符串），用于网关鉴权等场景 |
| 速率限制 | 对服务商配置请求频率限制 |
| Deeplink / 文件导入配置 | 通过导入链接或文件快速完成服务商配置 |

> ⚠️ **企业托管**：被企业统一下发的服务商带「托管」标识，其 Base URL 固定为推荐值不可修改（防止误改导致请求异常）。普通用户请勿改动服务商配置；对话报错、单据识别失败时联系管理员。

## 三、办公智能体 Agent

管理所有「办公智能体」类型的 Agent 及其**新会话默认值**。在此新建/编辑的 Agent 会出现在智能体选择页（见 [03-智能体](03-智能体.md)）。

> 📷 **截图待补充**：办公智能体 Agent 管理页 → `images/08-agents.png`

### 3.1 基本信息

| 配置项 | 说明 |
| --- | --- |
| 名称 | Agent 显示名（如 Writer / Research / Translate） |
| 启用状态 | 关闭后不在选择页出现 |
| 描述 | 可选，说明 Agent 用途 |

### 3.2 头像（三种方式）

| 方式 | 效果 |
| --- | --- |
| 默认 | 主 Agent 用默认图标，其余用文字头像 |
| Lucide 图标 | 从图标库选择，并分别设置浅色/深色主题颜色与背景色 |
| 文字头像 | 用前两个英文字母或首个汉字（如 WR / 研）区分 |

### 3.3 模型默认值

该 Agent 新会话的默认模型与生成参数：

- **默认对话模型 / 助手模型 / 视觉模型 / 图像生成模型**：四类用途分别指定。
- **生成参数**：温度、上下文长度、最大 Token 数、思考预算、推理强度、详细程度、强制兼容交错思考。

### 3.4 会话与工具默认值

| 配置项 | 说明 |
| --- | --- |
| 默认系统提示词 | 新会话自动携带的角色设定（留空则空白） |
| 默认目录 | Agent 工作目录（留空用全局默认） |
| 默认权限 | 「默认权限」或「全部启用」工具权限 |
| 内置工具 | 该 Agent 可用的内置工具开关 |
| 高级输出限制 | 控制「文件读取」与「工具输出」在上下文中保留的字符上限；超出时运行时自动转存或拒绝（有安全兜底） |

### 3.5 subagent（子任务委派）

允许该智能体把独立子任务委派给配置好的槽位（由模型自行判断何时使用）：

1. 打开「允许该智能体委派子任务」。
2. 添加槽位（有数量上限）：设置**目标类型**（当前智能体 / 指定其他智能体）、显示名称、槽位描述。
3. 委派会消耗额外的 token、时间和系统资源，按需开启。

## 四、智能信息提取（模板管理）

管理单据识别所用的**模板**：模板定义了一类单据要提取哪些字段。「管理智能信息提取模板，配置字段并测试提取效果」。

> 📷 **截图待补充**：智能信息提取模板管理页 → `images/08-docs-templates.png`

### 4.1 预置模板

预置模板按 **11 个类别**分组展示：合同类、出行票据类、采购类、支付凭证类、发票类、财务类、资产类、行政类、人事类、招投标类、自定义。每张模板卡片显示名称与字段数量，可：

| 操作 | 说明 |
| --- | --- |
| 查看 | 打开模板编辑器只读浏览 |
| 复制为自定义 | 以预置模板为底稿复制一份，再按需修改（推荐做法） |

### 4.2 自定义模板

- 点击右上角 **「新建模板」** 从零创建。
- 自定义模板支持**编辑**与**删除**；删除已被识别记录引用的模板时需**二次确认强制删除**。

### 4.3 与其他分区的关系

- 模型未配置时页面顶部出现黄色提示条，点击「去配置」跳转「智能信息提取模型」。
- 模板的 `type_key` 被「报销类别配置」引用做自动归类（见第七节）。

## 五、智能信息提取模型

为单据识别指定两个模型（路径：设置 > 智能信息提取模型，也可从文档页提示条跳转）：

| 配置项 | 用途 |
| --- | --- |
| **文本模型** | 从 OCR/文本层结果中做字段结构化提取 |
| **视觉模型** | 直接读取单据图片/PDF 页面的多模态模型 |

两项都选好后点击保存。**未配置时文档页顶部会常驻提醒且无法识别**。

## 六、模板编辑器

编辑单个模板的字段定义，并做**样张测试**。

### 6.1 字段编辑

每个字段包含名称、key 与取值类型；取值类型支持：**文本 / 数字 / 日期 / 数组 / 枚举**。

### 6.2 样张测试

1. 点击 **「选择样张」** 上传一张该类单据。
2. 系统实际跑一遍识别链路并展示每个字段的提取结果（字段 / 值 / 状态），并显示执行链路（视觉模型 → 文本提取 → OCR）与耗时（ms）。
3. 测试结果**不会存入档案**，仅用于验证模板配置效果；状态为「待确认」的字段表示提取值不确定，需人工留意。

## 七、报销类别配置

定义 [文件分组](05-文件分组.md) 的自动归类规则，包含**报销类别**与**字段映射与分组**两大块。

> 📷 **截图待补充**：报销类别配置页 → `images/08-reimbursement-config.png`

### 7.1 报销类别

每个类别包含：

| 配置项 | 说明 |
| --- | --- |
| 类别名称 | 如「交通费」「餐饮费」（必填、不可重复） |
| 自动归类模板 type_key | 逗号分隔的模板 key 列表；单据模板命中这些 key 时**自动归入该类别** |
| 所需材料清单 | 该类别报销要求的材料项（可新增多条）；每条材料可**关联模板 type_key**（可选），用于与已有单据自动对照 |

### 7.2 字段映射与分组

告诉文件分组如何从单据字段中找出归属信息：

| 配置项 | 说明 |
| --- | --- |
| 人员字段 key | 用哪些字段值确定「人员」归属 |
| 日期字段 key | 用哪些字段值确定「期间」归属 |
| 金额字段 key | 用哪些字段值统计金额 |
| 日期分组粒度 | **按月** / **按天** 分组 |

### 7.3 保存与校验

- 修改后点击「保存」生效，「重置」放弃修改。
- 校验规则：类别名称必填且唯一、材料名称必填、`type_key` 需 ≤64 字符且仅限小写字母/数字/下划线，违反时行内红字提示。

## 九、数据

建议定期关注本分区：

- **备份**：将会话、单据归档等本地数据导出备份。
- **恢复**：从备份文件恢复。
- **清理**：清理缓存等占用空间的临时数据（操作前请确认不影响归档数据）。

> ⚠️ 单据归档与文件分组数据保存在本机，更换电脑前请先做数据备份与恢复。

## 十一、常见问题

**Q：界面是英文的怎么改回来？**
「设置 > 显示 > 语言」选择「简体中文」。

**Q：升级后单据数据还在吗？**
在。升级不会删除用户数据；如不放心可在升级前于「数据」分区做一次备份。

**Q：换电脑如何迁移？**
旧电脑「设置 > 数据」导出备份 → 新电脑安装软件 → 「数据」导入备份。

**Q：文档页提示「模型未配置」？**
进入「设置 > 智能信息提取模型」，配置文本模型与视觉模型（联系管理员）。

**Q：文件分组没有自动归类？**
检查「报销类别配置」中类别的 `type_key` 是否与单据模板匹配，以及人员/日期字段 key 是否配置正确。
