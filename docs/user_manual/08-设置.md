# 08 设置

软件的全部配置项集中在「设置」中。

**入口**：左侧栏左下角 → **「设置」**

## 一、设置分区一览

| 分区 | 内容 | 普通用户是否需要动 |
| --- | --- | --- |
| 通用 | 基础行为设置 | 一般不用 |
| 模型提供方 | 配置 AI 模型服务与密钥 | ❌ 管理员负责 |
| 模型 | 各模型的参数与可用性检查 | 一般不用 |
| 智能信息提取 | 单据识别相关：模型、模板、报销类别、自动扫描目录 | ✔ 按需（见下文） |
| 知识库 | 本地知识库管理 | 按需 |
| 技能 | 技能包管理（亦可从「扩展」进入） | 按需 |
| MCP | 外部工具源配置 | ❌ 管理员负责 |
| 显示 | 主题、语言、字体等外观 | ✔ 常用 |
| 快捷键 | 自定义键盘快捷方式 | ✔ 常用 |
| 通知 | 消息通知行为 | 按需 |
| 计划任务 | 定时执行的任务 | 按需 |
| 数据 | 数据备份、导入导出、清理 | ✔ 建议了解 |
| 关于 | 版本信息、检查更新 | 偶尔 |

## 二、模型提供方（管理员）

AI 功能依赖模型服务。管理员在此配置：

1. 进入「设置 > 模型提供方」。
2. 添加提供方（如 OpenAI 兼容服务、Ollama 本地模型等），填写服务地址与密钥。
3. 启用需要的具体模型。
4. 可用「模型检查」验证连通性。

> ⚠️ 普通用户请勿修改模型配置；发现模型不可用（对话报错、单据识别失败）时联系管理员。

## 五、数据

建议定期关注本分区：

- **备份**：将会话、单据归档等本地数据导出备份。
- **恢复**：从备份文件恢复。
- **清理**：清理缓存等占用空间的临时数据（操作前请确认不影响归档数据）。

> ⚠️ 单据归档与报销整理数据保存在本机，更换电脑前请先做数据备份与恢复。

---

## 六、关于与更新

1. 进入「设置 > 关于」。
2. 查看当前版本号（如 1.2.8）。
3. 点击「检查更新」，有新版本时按提示升级。

---

## 七、常见问题

**Q：界面是英文的怎么改回来？**
「设置 > 显示 > 语言」选择「简体中文」。

**Q：升级后单据数据还在吗？**
在。升级不会删除用户数据；如不放心可在升级前于「数据」分区做一次备份。

**Q：换电脑如何迁移？**
旧电脑「设置 > 数据」导出备份 → 新电脑安装软件 → 「数据」导入备份。
